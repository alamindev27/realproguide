# Real Estate Pro Guide (`realproguide`) 🏠✨

A complete, modern, and high-performance UI redesign of the legacy **Real Estate Pro Guide** directory website. Built using **Tailwind CSS** and pure JavaScript, this web application transforms a traditional directory into an interactive, sleek, and user-friendly portal for real estate agents and homebuyers.

---

## 🌟 Key Features

* **Modern & Elegant Design**: Clean typography, premium color palette, and subtle visual card interactions.
* **Instant Search & Live Filtering**: Filter real estate agents dynamically by name, designation, state, or brokerage without page reloads.
* **Interactive State Directory**: Interactive grid showcasing all 50 US states with dynamic agent counters and quick-view toggling.
* **Featured Market Section**: Highlights weekly focused markets (e.g., Sacramento Real Estate Guide) with targeted CTA cards.
* **Featured Agent Showcase**: Professional profile cards displaying agent credentials (e.g., ABR®, CRS®, GRI), brokerage details, location, and quick contact buttons.
* **Monetization & Ad Spaces**: Dedicated, clean sidebars designed for sponsored listings and localized community announcements.
* **Fully Responsive**: Flawless layout across Desktop, Tablet, and Mobile devices.

---

## 🛠️ Tech Stack

* **HTML5**: Semantic markup for accessible and SEO-friendly structure.
* **Tailwind CSS (v3)**: Utility-first CSS framework for fast, custom styling.
* **JavaScript (Vanilla)**: Lightweight and fast interactive filtering and DOM manipulation.
* **Font Awesome**: Modern icon kit for visual elements and UI indicators.
